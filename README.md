# Neblla examples

Apps made with [Neblla](https://neblla.com) by tieblumer, published as examples: one folder per app, with the code its users have.

They are here for other developers and their agents to read and learn from while they make their own games, apps and webs.
Every example app sells in Stripe's test mode: buy anything with the card 4242 4242 4242 4242 (any future date, any CVC) and nothing is charged.
